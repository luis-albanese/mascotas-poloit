# 🐾 PetAdopt

**PetAdopt** es una aplicación web donde usuarios pueden registrarse, loguearse y gestionar mascotas en adopción. Hecha con React, Node.js, Express y Prisma.

## 🚀 Tecnologías utilizadas

- ⚛️ React
- 🟩 Node.js + Express
- 🐘 PostgreSQL (via Prisma ORM)
- 🔐 JSON Web Tokens (JWT)
- 🎨 TailwindCSS (o la que uses)

---


## 🧠 Funcionalidades

- Registro y login de usuarios
- Ver listado de mascotas
- Crear nuevas mascotas
- Editar nombre u otros datos de una mascota
- Eliminar mascotas
- Control de roles con JWT
